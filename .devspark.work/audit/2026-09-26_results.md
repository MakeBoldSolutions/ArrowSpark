## CONFIG1 — Unreadable settings are overwritten (CRITICAL)

**Location:** `addons/maaacks_game_template/base/scripts/config.gd:22–24`.

**Constitution:** VI, Preserve Saved Progress and Settings: “Changes MUST preserve
existing saved progress and settings, or provide an explicit migration/reset plan
when compatibility will break.” The same principle prohibits silent, unexplained
loss of progress. This finding concerns the settings-preservation obligation.

```gdscript
var load_error : int = config_file.load(CONFIG_FILE_LOCATION)
if load_error:
    var save_error : int = config_file.save(CONFIG_FILE_LOCATION)
```

**Trigger:** an existing `user://config.cfg` cannot be parsed. The loader treats all
load errors like a missing file and immediately saves its empty or partially loaded
ConfigFile back over the original. A subsequent write can also overwrite the data.

**Reproduction:** copied the current `config.gd` into a temporary Godot project with
isolated APPDATA/XDG_DATA_HOME and a unique project name. Wrote malformed settings,
cleared `Config.config_file`, and called `Config.load_config_file()`. Godot reported
an expected parse error and printed `CONFIG_ORIGINAL_PRESERVED=false`. Exit was zero;
the incorrect file contents, not the exit code, establish the defect. Actual player
data was not touched. This is an existing adjacent issue, not a regression attributed
to the recent progress-save fix.

**Intent:** preserve recoverable player settings when loading fails and provide an
explicit recovery choice, while continuing to use safe defaults in memory.

**Recommendation:** distinguish missing settings from failed existing-file loads.
On failure, preserve original bytes and prevent every settings-write path from
replacing them until an explicit reset/recovery action. Back up before reset, surface
the problem to the player, and test corrupt/partially parsed files, ordinary setting
changes while blocked, backup failures, and successful reset. Merely skipping this
one immediate save does not protect against subsequent setters.
