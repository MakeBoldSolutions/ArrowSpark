# Human playtest guide

Run `godot --path .` on a desktop. Select each of the six new entries in Level Select: Long Geometry, Interwoven Paths, Dense Core, Distinct Regions, Single Release, and Boundary Knot. Complete each puzzle yourself using normal selection; assistance is allowed and should be counted. The solver witnesses in the reference report are verification evidence and should not be used as play instructions.

After each completed puzzle, record in `.knowledge/reference/gordian-knot-experiments.md` under that puzzle's **Observed in this session** heading:

- Session date, author/reviewer role, play order, and whether the puzzle geometry still matches the documented catalog Git object.
- Completion, mistakes, open-move assists, final score and accuracy from the results panel.
- Perceived challenge, how much tracing you had to do, and whether removing arrows felt satisfying.
- One removal that visibly simplified the board, or an explicit statement that none did.
- Whether you used zoom, pan and fit; whether each helped; whether individual arrows stayed readable.
- Overall qualitative verdict, including negative reactions, and any familiarity or order effect.

A zero assist/mistake count is different from unknown. If geometry changes after a session, replay that puzzle before using the observation. After all six sessions, compare objective measurements with what you experienced and record cautious supported/contradicted/inconclusive verdicts and contradictions in the report's Interpretation and Cross-experiment synthesis sections. One session does not establish a universal design rule.

Also exercise desktop keyboard and gamepad menu/toolbar focus, remapping, mouse selection, pause/resume, restart, replay, Next, and return to menu at 960x540, 800x800 and 1280x720. Record checks and any defects in verification.md. Automated checks cover logic but cannot establish input feel or personal satisfaction.
