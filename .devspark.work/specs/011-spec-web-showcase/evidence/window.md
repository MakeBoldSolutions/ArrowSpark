# Learning window

The window is 14 days from the day the showcase is first publicly reachable at `https://arrow.makeboldspark.com`. It is never extended.

| Field | Value |
|---|---|
| `published_reachable_at` | (not yet published) |
| `closes_at` | (published + 14 days) |
| `api_available_from` | (when the reactions endpoint first accepts submissions, if later) |
| Daily synthetic check enabled / disabled | |
| Feedback closed (site rebuilt with `PUBLIC_FEEDBACK_CLOSED=true`) | |
| Raw session notes deleted | |
| Reaction files and private copies purged (API project) | |
| Endpoint disabled (API project) | |
